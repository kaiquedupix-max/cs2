# Como contribuir

As contribuições ao legitbaratinho.xyz devem respeitar a licença GPL-3.0 e as licenças de terceiros.

- Verifique se o código compila e se a alteração funciona.
- Siga a formatação e o estilo existentes no projeto.
- Escreva mensagens de commit claras, usando prefixos como `feat:`, `fix:` e `docs:`.
- Consulte os problemas e discussões existentes antes de abrir uma nova solicitação.
- Descreva o comportamento esperado e forneça exemplos para relatos de falhas.
- Trate autores, colaboradores e mantenedores com respeito.

Preserve os créditos dos autores originais e os avisos de licença.
